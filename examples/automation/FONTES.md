# Procedência pública

- Código, interface, textos e fixtures criados para a demonstração de automação do Fabio em 16/11/2026. Licença MIT.
- Não foram copiados dados, bancos, configurações, arquivos escolares ou código dos sistemas internos.
- Reutilizados o Python padrão e as ferramentas de verificação/captura já instaladas. A ideia de validar, deduplicar, registrar exceções e comprovar repetição foi mantida; nenhuma integração privada foi incorporada.
- Nomes de empresas, produtos, pedidos e e-mails são fictícios. Os e-mails usam domínios `.example`; exemplos de teste também usam `example.test`. Não representam clientes atendidos.
- Uma chamada local ao fluxo `fabio-codigo` foi tentada apenas para uma função pequena de normalização. Escalou por permissão na trava, antes de produzir rascunho. Não foi repetida. O principal implementou/revisou a função e os testes; nenhum código de modelo local foi aplicado.
- A CLI usa somente módulos da biblioteca padrão do Python. O runtime Python não é redistribuído; sua documentação/licença está em [Python — History and License](https://docs.python.org/3/license.html).
- Capturas: relatório gerado pelo próprio programa, aberto em Edge offline e operado por Playwright. Vídeo: sequência dessas capturas codificada pelo FFmpeg existente, sem áudio, música, imagem de terceiros ou software novo. Ferramentas de captura não são incorporadas ao pacote.
- Não há métricas de tempo economizado, aumento de vendas ou produtividade. As quantidades exibidas vêm da fixture e podem ser reproduzidas pelo comando documentado.

O pacote foi preparado para revisão do integrador GitHub e do dono do portfólio.
Este produtor não publicou repositório, item de portfólio, anúncio ou mensagem.
